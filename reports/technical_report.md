# Technical Report: Norwegian Production Analytics

## Objective
This project analyzes real monthly oil and gas field production data from the Norwegian Offshore Directorate.

## Dataset
The dataset contains field-level monthly production records, including oil, gas, NGL, condensate, oil equivalent, produced water, year, month, and field identifiers.

## Workflow
1. Loaded real production data
2. Cleaned column names
3. Created a monthly date column
4. Saved processed data
5. Performed exploratory data analysis
6. Visualized production trends
7. Built a baseline next-month oil production forecasting model

## Key Skills Demonstrated
- Python data analysis
- Pandas data cleaning
- Time-series feature engineering
- Data visualization
- Machine learning model training
- Technical reporting

## Limitations
This is an educational portfolio project. The model is a baseline and does not include detailed geological, reservoir, or operational constraints.
